# Contributing

Contributions are welcome: bug reports, ideas and pull requests.

- **Bugs and ideas:** open an issue. Never paste message content, phone numbers, keys or anything from your `profiles/` folder.
- **Code:** read [`src/README.md`](src/README.md) for the code map and how to run the tests (`cd src && make test`). Keep changes small and in the style of the surrounding code.
- **CLA:** every pull request must include the line *"I have read and agree to the CLA in CLA.md."*. See [CLA.md](CLA.md) for the reason.

By contributing you agree that your contribution is licensed under the project's license ([AGPL-3.0](LICENSE)) and under the terms of the [CLA](CLA.md).
